# Docker Container Update Script

A script to update Docker containers

# Installation

To use this application, follow the steps below:
1. Install curl if you haven't already

`sudo apt install curl`

2. Download the Docker Manager script

`curl -LJO https://git.switchit.me/Jeroen/linux-scripts/raw/branch/main/docker-updating-containers/container-update.py`

3. Make the script executable

`sudo chmod +x container-update.py`

4. Start the program

`./container-update.py`


# Usage

Run the script in the terminal and add container name(s).

Example:

`container-update.py container1 [container2] [container3]`

Container names between [] are optional.
